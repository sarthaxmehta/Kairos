# Kairos Staff Counter Operations Application (`apps/staff`)

## Overview
The **Staff Operations Application** is designed for counter operators, doctors, desk representatives, and service technicians:
1. Counter status control (`ACTIVE`, `ON_BREAK`, `OFFLINE`).
2. Single-click counter actions: **Call Next Customer**, **Start Service**, **Complete Service**.
3. Exception management: **Skip No-Show**, **Transfer to Department**, **Override Priority**.
4. Real-time queue velocity & workload performance tracking.

## Port & Environment
- **Default Dev Port**: `http://localhost:3001`
- **Tech Stack**: Next.js App Router, React, CSS Modules, Real-time WebSockets.
