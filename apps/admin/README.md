# Kairos Admin & Operations Dashboard (`apps/admin`)

## Overview
The **Admin & Operations Dashboard** is the control center for tenant administrators and branch managers:
1. Multi-branch, multi-department, and service counter configuration.
2. Staff role allocation & Role-Based Access Control (RBAC).
3. Real-time operations visualizer and bottleneck heatmaps.
4. Operational analytics: SLA compliance, wait time trends, peak hour distribution, and staff throughput.
5. AI Operations insights: SLA anomaly detection and natural language query assistant.

## Port & Environment
- **Default Dev Port**: `http://localhost:3002`
- **Tech Stack**: Next.js App Router, React, CSS Modules, Charting libraries.
