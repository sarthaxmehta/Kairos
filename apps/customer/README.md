# Kairos Customer Application (`apps/customer`)

## Overview
The **Customer Application** allows end users to:
1. Book appointments online.
2. Join virtual queues and receive digital queue ticket tokens.
3. Track live queue status and estimated wait times in real time.
4. Receive WhatsApp / Push notifications when their turn approaches.
5. Provide instant feedback and post-service ratings.
6. Interact with the Natural Language AI Assistant for quick bookings and status checks.

## Port & Environment
- **Default Dev Port**: `http://localhost:3000`
- **Tech Stack**: Next.js App Router, React, CSS Modules, WebSockets client.
